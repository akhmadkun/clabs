BASELINE
- All four adjacencies are point-to-point OSPFv2 in Area 0.0.0.0.
- The Junos default metric is 1 on each link; don't configure explicit metrics.
- The default interface timers expected in this lab are Hello 10, Dead 40, ReXmit 5.
- R1 reaches R4's 10.1.1.4/32 loopback over two equal-cost routes with a total OSPF metric 2 when all links are healthy.

INCIDENT PROFILE
- In the opening incident profile, only R3's eth1.13 has an explicit Hello interval override. It is intentionally incompatible with the peer's default timer state.
- Use `configs/r3/lab015-r3-incident-start.set` at the start instead of `configs/r3/lab015-r3-baseline.set`.

CONVENTIONS
- VLAN ID and logical unit match the two-digit router pair.
- IPv4 point-to-point links use /30.
- All parent eth1 interfaces attach to the externally managed pre-existing `br-univ`; do not change it.
