LAB-011 ADDRESS PLAN — OSPFv2 AREA RANGE

ROUTER IDs
R1 10.1.1.1/32 (ABR; Area 0 + Area 1)
R2 10.1.1.2/32 (Area 0)
R3 10.1.1.3/32 (Area 1)
R4 10.1.1.4/32 (Area 1)
R5 10.1.1.5/32 (Area 1)

LOGICAL LINKS — VLAN ID = ROUTER-PAIR ID; SUBINTERFACE UNIT = VLAN ID
Pair   VLAN  Subinterface endpoints            Subnet          Endpoint IPs
R1-R2  12    R1 eth1.12 / R2 eth1.12          10.0.12.0/30    R1 .1, R2 .2 — Area 0
R1-R3  13    R1 eth1.13 / R3 eth1.13          10.0.13.0/30    R1 .1, R3 .2 — Area 1
R3-R4  34    R3 eth1.34 / R4 eth1.34          10.0.34.0/30    R3 .1, R4 .2 — Area 1
R4-R5  45    R4 eth1.45 / R5 eth1.45          10.0.45.0/30    R4 .1, R5 .2 — Area 1

SERVICE LOOPBACKS — AREA 1
R3 lo0.0: 192.168.11.3/32
R4 lo0.0: 192.168.11.4/32
R5 lo0.0: 192.168.11.5/32
These coexist on lo0.0 with the existing router-ID /32 address. Do not create extra lo0 units; cRPD can reject multiple loopback units in the master routing instance.

SUMMARY CONFIGURATION TARGET
On R1 only:
  protocols ospf area 0.0.0.1 area-range 192.168.11.0/24

BEHAVIOR
Before range: R2 learns the three service loopbacks as individual OSPF routes.
After range: R2 should learn 192.168.11.0/24 as an OSPF summary route, while the matching /32 specifics are suppressed across the Area 1/Area 0 boundary.

CONVENTIONS
- Point-to-point links use /30 with .1 on the lower-numbered router and .2 on the higher-numbered router.
- Keep router IDs unique.
- All parent eth1 interfaces connect to the already-existing host bridge `br-univ`; logical link VLAN tags are configured on Juniper subinterfaces.
- This lab assumes the user's corrected universal topology maps R5 to parent `eth1` (not `eth5`). No topology YAML change is required for this lab.
