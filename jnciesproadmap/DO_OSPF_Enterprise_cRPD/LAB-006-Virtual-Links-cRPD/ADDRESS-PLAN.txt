LAB-006 - OSPF VIRTUAL LINKS
ADDRESS PLAN AND LOGICAL VLAN MAPPING
Source: Day One: Advanced OSPF in the Enterprise, Chapter 7.

PHYSICAL CONNECTIVITY
  R1, R2, R3, R4 and R10 attach parent eth1 to the existing host bridge br-univ.
  R4 eth2/eth3/eth4 connect directly to EP16/EP17/EP18.
  R10 eth2/eth3 connect directly to EP76/EP77.
  This lab references but does not create or delete br-univ.

ROUTER LOOPBACKS / ROUTER IDS TO CONFIGURE MANUALLY
  R1 lo0.0  10.1.1.1/32
  R2 lo0.0  10.1.1.2/32
  R3 lo0.0  10.1.1.3/32
  R4 lo0.0  10.1.1.4/32
  R10 lo0.0 10.1.1.10/32

LOGICAL ROUTER LINKS
  Area 0 / VLAN 12 / broadcast:
    R1 eth1.12 10.0.12.1/24 <----> R2 eth1.12 10.0.12.2/24
    DR/BDR review: R1 priority 255, R2 priority 100 on a fresh election.

  Area 1 / VLAN 13 / point-to-point:
    R1 eth1.13 10.0.13.1/30 <----> R3 eth1.13 10.0.13.2/30

  Area 2 / VLAN 24 / point-to-point:
    R2 eth1.24 10.0.24.1/30 <----> R4 eth1.24 10.0.24.2/30

  Area 2 / VLAN 410 / point-to-point:
    R4 eth1.410 10.0.41.1/30 <----> R10 eth1.410 10.0.41.2/30
    VLAN ID 410 follows the R4-R10 link pair; IPv4 uses 10.0.41.0/30 because
    an IPv4 octet cannot be 410. The link is part of transit Area 2.

AREA 2 CONNECTED NETWORKS BEHIND R4
  R4 eth2.0 192.168.16.1/30 <----> EP16 eth1 192.168.16.2/30
  R4 eth3.0 192.168.17.1/24 <----> EP17 eth1 192.168.17.2/24
  R4 eth4.0 192.168.18.1/23 <----> EP18 eth1 192.168.18.2/23

AREA 3 CONNECTED NETWORKS BEHIND R10
  R10 eth2.0 192.168.76.1/24 <----> EP76 eth1 192.168.76.2/24
  R10 eth3.0 192.168.77.1/24 <----> EP77 eth1 192.168.77.2/24
  Make R10's eth2.0, eth3.0 and lo0.0 passive in Area 3.

EXPECTED AREA ROLES
  R1: Areas 0 and 1 (ABR)
  R2: Areas 0 and 2 (ABR; one virtual-link endpoint)
  R3: Area 1 (internal router)
  R4: Area 2 only (transit router)
  R10: Areas 2 and 3 (ABR; other virtual-link endpoint)

VIRTUAL LINK
  R2 config:  area 0.0.0.0 virtual-link neighbor-id 10.1.1.10 transit-area 0.0.0.2
  R10 config: area 0.0.0.0 virtual-link neighbor-id 10.1.1.2 transit-area 0.0.0.2
  Both statements are configured under the Area 0 OSPF hierarchy. Transit Area 2
  must remain a normal OSPF area and must have full routing information.

CONTAINERLAB / STARTUP CONFIG NOTES
  cRPD eth0 is management; eth1 is the first data interface; further data
  interfaces are eth2, eth3, etc. Startup configs set addressing and VLAN IDs
  only. Router IDs, OSPF area assignments, passive interfaces and virtual links
  are configured by the learner during the task.
