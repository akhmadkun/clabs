LAB-003 - OSPF REDISTRIBUTION AND DUAL DEFAULT ROUTES
ADDRESS PLAN AND LOGICAL VLAN MAPPING

PHYSICAL TOPOLOGY
  R1 eth1 ----+
  R2 eth1 ----+---- existing host Linux bridge br-univ
  R3 eth1 ----+
  R4 eth1 ----+

The bridge is one shared Layer-2 broadcast domain and is not an OSPF area.
OSPF adjacencies are separated by 802.1Q VLAN subinterfaces.
The topology diagram intentionally omits the physical bridge.

STATIC ROUTES FOR REDISTRIBUTION EXERCISES
  R4: 192.168.29.0/24 via 192.168.16.2
  R4: 192.168.30.0/24 via 192.168.16.2
    Expected purpose: redistribute two explicitly selected static routes into
    OSPF as Type-5 external LSAs. The endpoint does not actually host those
    destinations, so end-to-end reachability is not an acceptance criterion.

  R4 decoy: 198.51.100.0/24 discard
    Expected purpose: keep this active static route out of OSPF because the
    export policy should match only 192.168.29.0/24 and 192.168.30.0/24.

  R1: 0.0.0.0/0 discard
  R2: 0.0.0.0/0 discard
    Expected purpose: originate two independent Type-5 external default LSAs,
    one from each Area 0 router, after an exact-match export policy is applied.
    These discard routes are a control-plane simulation only, not Internet paths.

  R3 adaptation routes: 192.168.71.0/24 discard and 192.168.72.0/24 discard
    Expected purpose: observe Type-5 external LSAs originated by R3 in normal
    Area 1. The ebook uses RIP-learned routes from a separate R5; this lab keeps
    the four-router physical topology and uses static routes instead. It does
    not claim to demonstrate RIP-to-OSPF redistribution.

OSPF CLASSIFICATION
  Internal route: learned inside an OSPF area (intra-area).
  Inter-area route: learned through an ABR / Type-3 Summary LSA.
  External Type 5: a route redistributed into the OSPF domain by an ASBR.
  E1 metric includes internal OSPF cost plus external metric.
  E2 metric primarily compares the external metric; E2 is the Junos default
  external metric type unless changed by route policy.

CONTAINERLAB INTERFACE NOTES
  cRPD eth0 is the management interface; eth1 is the first data interface.
  The parent data interface eth1 carries the 802.1Q VLANs configured as
  eth1.12, eth1.13, and eth1.24 in Junos. R4 eth2/eth3/eth4 connect to hosts.
  The four startup configs contain addressing only. Configure router IDs,
  OSPF, static routes, policy statements, and OSPF export policy manually.
