SOURCE-DERIVED PRINCIPLES
- ABRs can aggregate a range of IP addresses to reduce the number of summary advertisements flooded into another area.
- For a normal OSPF area, an area range summarizes intra-area prefixes. Matching routes are filtered at the area boundary and the summary is advertised in their place.
- For an NSSA, area-range functionality relates to NSSA external Type 7 LSAs before translation to AS-external Type 5 LSAs; this lab does not configure an NSSA.
- Juniper's separate `prefix-export-limit` option limits the number of prefixes exported into OSPF. This is not the same feature as area-range summarization and is outside this lab's scope.
