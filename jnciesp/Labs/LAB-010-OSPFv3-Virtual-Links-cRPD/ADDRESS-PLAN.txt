VLAN CONVENTION
The VLAN ID matches the router pair: 14, 23, 34, 36, 46, 610. Endpoint with lower router number uses ::1, higher router number uses ::2. Interface unit number equals VLAN ID. Any future exception must be documented rather than assigning an arbitrary VLAN.
