Endpoint return routes: configure-hosts.sh adds routes to 10.1.1.0/24 and
192.168.0.0/16 via each endpoint subnet's R4 address. These routes allow a
remote OSPF router to ping an endpoint and receive the reply.

SUMMARY PREFIX
192.168.16.0/21 covers 192.168.16.0 through 192.168.23.255.
It contains the three connected prefixes above and leaves room for growth.

INTERFACE NAMING NOTE
Containerlab's cRPD kind uses eth0 for management, eth1 as the first data
interface, and eth2 onward for subsequent data interfaces. The CLI uses eth1,
eth2, etc. as well. In the Junos configuration, IPv4 addressing is configured
under logical unit 0 (for example, interfaces eth1 unit 0 family inet address).
Do not replace these cRPD interface names with ge-0/0/x names from a physical
Junos router example.
